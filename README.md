# Luz Design

面向中文产出的视觉与排版设计技能（Agent Skill）：规定所有 Luz 产出共用的视觉标准，负责海报与品牌视觉，以及报告、网页文档、Excel、Word、演示文稿等文件的版式。

## 能做什么

- **视觉标准**：配色从官方色板按行业气质取阶（附 17 个行业主题），一条统一的中文字体栈与各类产出的字阶，扁平线性风格，一套线宽统一的线性图标，圆角、阴影、间距与动效；系统设计技能的界面都以此为准。
- **海报与品牌视觉**：活动海报、品牌主视觉、宣传图，安全区、文字层级、缩略图辨识与版权边界；照片可用本机图像生成服务生成。
- **文件排版**：
  - Excel：单工作表、12 磅起、无序号、分组名纵向合并、一格一事实、浅色层次，由脚本直接生成。
  - Word：合同（当事人、条款、金额大写、签署栏、第几页共几页）、方案、报告、会议纪要、制度、公文，按类型排版，由脚本直接生成。
  - 报告与网页文档、演示文稿、PDF、Markdown 的标题、字号、表格与图表规则。
- **自动检查**：文件检查脚本拦截小字号、多字体、深色大面积、装饰渐变与立体效果、图标混用、文字头像、表格合并错误、合同缺项与占位文字等常见问题；Luz System、Luz Dev、Luz Writing 也用它检查各自的页面。
- **经验库**：沉淀配色、字阶、视觉与文件规则，下一个项目先查库。

## 典型用法

把本目录放进 Agent 的技能目录后，直接提需求，例如：

- “做一张健身房周年庆的活动海报。”
- “把这份调研结果整理成一个单工作表的 Excel，类别合并、加浅色底。”
- “按这些条款排一份设备采购合同的 Word。”
- “这份方案的配色和字号帮我按规范调整。”

系统设计、产品界面、可交互原型与硬件选型请用 [Luz-System](https://github.com/luzern0414/Luz-System)。

## 目录结构

```text
SKILL.md          技能入口：分工、路由、规则摘要
WORKFLOW.md       各阶段的进入条件与停止条件
references/       视觉设计规范、文件设计规范、行业主题库、生图提示词模板、会话模板
experience/       经验库：配色、字阶、视觉与文件规则
scripts/          文件检查、对比度检查、Excel 与 Word 生成、建会话、发布、校验、测试
agents/           Agent 平台配置
```

## 依赖

- Python 3.11 及以上；`openpyxl`、`python-docx` 用于表格与 Word。
- 调研依赖 [Luz-Crawl](https://github.com/luzern0414/Luz-Crawl)；图片生成为可选能力，需要本机的图像生成服务。
- 默认把产出写到 `D:\Codes\skill输出\Luz-Design\`。

## 五个技能的分工

| 技能 | 负责 |
|---|---|
| [Luz-System](https://github.com/luzern0414/Luz-System) | 系统设计：软件方案、界面与原型、硬件选型 |
| **Luz-Design**（本仓库） | 视觉标准、海报与品牌视觉、文件排版 |
| [Luz-Dev](https://github.com/luzern0414/Luz-Dev) | 后端、接口、数据库、部署与上线 |
| [Luz-Writing](https://github.com/luzern0414/Luz-Writing) | 文章、文案、协议等文字内容 |
| [Luz-Crawl](https://github.com/luzern0414/Luz-Crawl) | 真实浏览器检索与采集 |
