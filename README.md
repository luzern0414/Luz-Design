# 🎨 Luz-Design

把已有内容做成好读、好找、好用的界面和文件。适合制作网站和小程序的页面，也能排版海报、演示文稿和客户资料。

## 它能帮你做什么

- **设计页面**。按已确认的功能安排重点。应用画布和全局导航纯白，界面禁绿与青绿，头像使用图形，业务办理进入独立页面。执行范围见[成品要求](references/design/hard-rules.md)。
- **制作可体验的样稿**。先看看实际页面，试一试按钮、列表和表单，再决定是否调整。
- **整理文档版面**。把现有文字、表格或图示做成适合阅读和分享的文件，也可以沿用已有品牌风格。
