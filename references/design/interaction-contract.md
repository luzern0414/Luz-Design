# 可复用交互合同

App 与 Web 的列表、详情、编辑与数据模块怎样落成结构。按 [成品要求](hard-rules.md) 核对行为。本页的控件样式是模板起点。

## 先定操作类型

| 操作意图 | 默认状态 | 触发后的结构 | 退出与提交 |
|---|---|---|---|
| 查看对象详情或预览 | 列表与卡片只读 | 短内容紧邻当前对象；长内容进独立详情页 | 左上返回，恢复原对象、筛选、位置与焦点 |
| 修改一个现有字段 | 字段文本加编辑入口 | 同一字段原位变输入；保存取消紧邻同排 | 成功原位更新；失败保留输入；取消还原 |
| 创建对象或补充业务记录 | 只显示所属模块的入口 | 独立填写页，自动带入相关上下文 | 一次提交完整业务；新增保留历史；返回来源 |
| 数字或进度选择 | 表单进入前没有输入 | 字段内纵向滚轮与手输共用一个值 | 停止惯性、同步输入后提交；快捷范围不是上限 |
| 业务筛选 | 可见的已选条件 | 更新所属内容，按宽度选控件 | 保持其它区域和主导航状态 |
| 结果提示或警告 | 没有预先展示的确认取消 | 近处状态，或居中通知与确认 | 不含填写表单；确认与取消相邻 |

每个入口写清 `对象 ID → 动作 → 结果区域或页面 → 提交接口 → 返回锚点`，写在组件与交互记录里，不显示给产品用户。没有业务用途的槽位直接省略。

## 实现映射

| 合同 | HTML 模板（`kit/ui.js`） | Vue 起点（`kit/frontend/shared/interaction.js`） |
|---|---|---|
| 模块，标题在卡外 | `.section` 加 `.section__head` | `UiSection`，`actions` 插槽放新建图标 |
| 就近展开 | `[data-expand]` 控制 `.expand`，配对 `aria-expanded` 与 `aria-controls` | 行内条件渲染 |
| 独立详情 | `[data-open]` 打开 `[data-view]`，`[data-back]` 返回，恢复滚动与焦点 | `UiDetailPage`，触发按钮用稳定 `data-ui-open` |
| 独立填写页 | `data-view` 视图加 `.subbar`，取消保存同排 `.btn-group` | `UiFormPage`，明确触发后才挂载 |
| 原位改字段 | 页面脚本切换文本与输入 | `UiInlineField` |
| 数字与进度 | `.wheel`，`Lz.syncWheels` 提交前同步 | `UiWheelField` |
| 具体日期 | 内嵌选择器，整表提交前同步；不用 `type="date"` | `UiDateField` |
| 悬浮说明 | `[data-tip]`，悬浮、焦点、移入、Escape | `UiHint` |
| 轻提示与确认 | `Lz.toast`、`Lz.confirm` | Element Plus 消息与对话框，确认框居中 |

已有其它工程沿用其路由与成熟控件，实现等价合同，不为模板换栈。多层详情与填写页，父页面保持挂载并隐藏，避免父子同时退栈；浏览器后退、应用返回、取消、保存都要实际测。

## 周期与权限

- 填写的业务日期是具体年月日，汇总周期由服务端按同一日历规则计算，两者分开保存与展示；历史只有周汇总时不伪造单日。
- 周期模块接收周期规则、业务时区、当前周期、选中周期与维护角色；图表只消费选中周期的数据，列表分类不反向控制顶部概览。回顾最多选到当前周期。
- 计划与配额由授权角色维护，其他角色只读；前端隐藏与服务端拒绝两层都要验证，未知计划不写零。

## 验收一条操作链

1. 保存点击前的位置与对象，再操作，确认结果现在可见。
2. 首项、中间项、末项和长列表分别测；不能只用一条数据测试。
3. 独立详情：标题与主要内容立即可见，焦点进入新页面，返回恢复来源。原位展开：确属当前行，首个有效结果在视野内。
4. 填写页：合法默认值、手输超出快捷范围、滚动未停就提交、中文输入法、校验失败、取消与返回。只在隔离的测试数据上提交。
5. 在目标宽度及更窄宽度看文字、状态、模块归属与固定底栏附近的内容。
6. 记录具体动作与实际结果；源码扫描不能代替这些验证，未验证的真机、服务端与外部生成能力写明留在交付边界。

资料到生成内容的流程保留 `来源对象 → 原始资料 → 提取依据 → 可操作结果`：重试复用原始资料，修改纪要后重新提取需求，异步返回要校验账号、对象与范围，不覆盖用户已经切走的新内容。通用模板不预填具体行业流程。
