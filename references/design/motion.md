# 动效

动效只用来解释空间、状态变化和操作反馈。取值在 `kit/tokens.css`，配方在 `ui.css` 与 `ui.js`，每项都能在 `templates/app/app.html`、`templates/web/web.html` 组件库里的动效分类（`MOTN`）里点“播放”实际观察。

## 判断顺序

1. **要不要动。** 说清它解释什么：空间关系、状态变化或操作反馈。说不清就不加。
2. **多频繁。** 高频操作（切换标签、勾选、输入）即时响应，只保留很短的状态过渡；低频、有仪式感的操作（成功、首次出现）才用较长的入场。
3. **能不能中断。** 快速连点、反向操作、中途关闭都要稳定，动画不阻塞下一次操作。

## 令牌

| 令牌 | 值 | 用在 |
|---|---|---|
| `--dur-instant` | 90ms | 按压反馈 |
| `--dur-quick` | 150ms | 悬停、选中、下拉 |
| `--dur-base` | 220ms | 展开、视图切换、浮层 |
| `--dur-slow` | 320ms | 入场、弹性、图表生长 |
| `--stagger` | 40ms | 列表与卡片错峰 |
| `--ease-out` | cubic-bezier(.22, 1, .36, 1) | 进入、展开，默认曲线 |
| `--ease-in-out` | cubic-bezier(.65, 0, .35, 1) | 位置移动 |
| `--ease-spring` | cubic-bezier(.34, 1.4, .64, 1) | 开关、勾选、徽标这类小元素的轻微回弹 |

退出比进入短一档。循环动画（骨架流光、抖动）用线性。大面积元素不用回弹。

## Three.js 空间动效

- 检查是否要解释前后层次、产品角度或空间转场。空间效果用 Three.js，输入、筛选、卡片点击等反馈沿用轻量 CSS。正文和业务数据保留在可读的 HTML 中。
- 组件库的「空间层叠」可用 `WB-MOTN-014` 或 `AP-MOTN-020` 找到。页面先显示静态图形，点击播放才加载本地 Three.js 并渲染一次。项目只在需要空间效果的区域接入。
- 取用组件时，从原示例复制 `data-three-motion` 容器，保留静态画面与播放按钮。复用 `kit/kit.css` 中对应样式和 `kit/three-motion.js`，随脚本带上同目录下的 `vendor/three/three.min.js` 与许可证。
- 画布跟随实际容器尺寸，限制像素比。完成、离开视口或切到后台时停止绘制，释放几何体、材质和渲染器。开启减少动态效果、WebGL 2 不可用或加载失败时，显示同一份静态图形。 [Three.js 响应式画布](https://threejs.org/manual/en/responsive.html) · [Three.js 资源清理](https://threejs.org/manual/en/cleanup.html) · [WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)

## 实现要求

- 普通 CSS 动效优先用 `transform` 与 `opacity`，操作状态可短暂过渡前景色。高度变化用网格行高过渡，属性逐项列出。
- 系统开启“减少动态效果”时（`prefers-reduced-motion: reduce`），时长压到近 0，位移与缩放去掉，状态变化与最终内容仍完整显示。缩放和平移大面积元素是前庭不适的主要诱因，这类动效优先让位。
- 动效不延迟操作：点击立即生效，装饰动画并行。
- 不用装饰性循环动画占位；加载只用骨架或进度。
- 浮层遵守硬规则：确认框居中，无方向滑入；表单进入独立页面，不做弹层与抽屉动画。
- 实际观察动效再定数值：快速连点、反向、关闭中途，以及低端设备上的掉帧；不凭时长数字宣称流畅。

## 参考与取舍

方法参考 [Transitions.dev](https://transitions.dev/) 的做法：把时长、距离、缩放、模糊、缓动做成变量，每个效果只引用变量，并提供可重放的预览；其库的许可禁止作为竞争性过渡库再分发，因此本库只借鉴方法，配方与代码为自写。时长与频率的取舍参考 Emil Kowalski 的动画方法，减少动态依据 MDN 的 `prefers-reduced-motion` 说明。来源与许可见 [参考来源](sources.md)。
