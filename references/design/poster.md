# 海报

先定受众、渠道与观看距离，用标题和主视觉让受众快速识别主题。以下构图和字级是建议，画幅、裁切、印刷和发布规格按实际渠道要求核对。

## 本库模板

`templates/poster/` 有十二个固定画布的单文件海报（`PS-001` 至 `PS-012`：促销、新品、优惠券、节日长图、开业横版、会员招募、课程招生 A4、招聘 A4、单品陈列、品牌故事、数据海报、节日祝福）和六十条海报与素材提示词（`PP-001` 至 `PP-060`）。

- 打开 `templates/poster/poster.html`（tab：海报模板、提示词库）预览十二个海报，顶部换主题色、背景效果、图标，复制编号；`py -X utf8 scripts/template_registry.py show PS-003` 取模板信息。
- 模板里的文字是可编辑文本，样式只用主题变量，`?theme=green` 换主题色；A4 的 `?bleed=1` 带 3mm 出血与裁切线。导出用 `scripts/export_poster.py <海报.html> <成品.png|pdf>`，PDF 是屏幕色彩空间，印刷的 CMYK 与字体嵌入交给印厂或排版软件。
- 提示词库在 `templates/poster/source/prompts/`：`PP` 编号，按商品摄影、场景主视觉、背景与纹理、图标拼板、空态插画、对象标识、海报主视觉、人物头像分类；主题色用占位，页面里换主题后复制。标“已验证”的七条是真实生成并被采用过的，其余是未生成过的起点，首次生成后要看图复核。
- 按素材比例与信息量调整模板。需要二维码时，用真实目标替换占位并实测扫码。

## 先定五件事

1. **渠道与观看距离**：印刷张贴、手机刷到、屏幕轮播，决定字号与信息量。
2. **尺寸与比例**：按媒介定，数值以印厂或平台当前要求为准。
3. **信息优先级**：第一眼读到什么、第二眼读到什么；时间、地点、条件、落款是必须保留的事实，缺失的事实不代填。
4. **真实素材**：有权使用的照片、品牌资产，缺图时用 Imagegen 生成图案与图标；不冒用他人品牌和人物。
5. **成功信号**：看完能记住或做什么，据此删掉其余内容。

## 规格

| 媒介 | 常用规格 | 要点 |
|---|---|---|
| 印刷 | A3、A4 等，出血 3mm，300dpi | 色彩模式按印厂（常为 CMYK），字体嵌入或转曲，重要内容离裁切线留安全边 |
| 手机竖图 | 4:5、3:4、9:16 | 以实际显示宽度看字号；平台界面会遮挡上下边缘，留出安全区 |
| 横幅与头图 | 按位置的宽高比 | 主体居中，文字不贴边，缩略后仍能辨认 |
| 动态海报 | 循环、短视频 | 验证循环衔接、阅读时间；每秒闪烁不超过 3 次 |

## 构图方法

- **一个主标题。** 标题、图像或主数字可以承担第一视点。标题通常简短，文字较长时可自然断成两行。时间、地点、价格、资格和行动说明用较弱的层级承接。口号有独立信息价值时可作辅助文案。
- **三类常用构图。** 产品和活动可先选一张主图再给文字留空；招募与讲座可用标题和时间地址作为主轴；数据海报可用一个关键数值或图表吸引视线。尺寸改变时重新安排裁切、字阶和留白。
- **颜色按渠道分工。** 用背景色承托图文，用品牌或主题色形成第一视点，用强调色突出关键信息。照片色彩丰富时可从照片取色，文字区用低纹理底或留白。放在手机缩略图和目标观看距离看主标题、细节和对比。
- 准确文字保留为可编辑文本，不交给生成图片；图片里的文字不承担事实。
- 二维码须有真实目标并验证可扫，印刷时留足静区与边长。
- 图表只在数据本身是传播内容时使用，不为“非文字”添加无关图形。

## 交付与验证

- 交付完整画面、所需源文件与导出规格；原图与派生图分开，登记生成提示词、回执与用途。
- 看全幅和实际观看尺寸，核对第一眼看见的内容、日期地点与条件、文字行尾和图像裁切。印刷查出血、安全边、色彩模式、字体与分辨率。
- 静态海报不执行 UI 点击清单。UX 看信息能否辨认，DX 看源文件、字体与导出能否复现，AX 看内容与素材清单能否定位和重用。

根据使用渠道和给定素材确定主次、裁切、留白与字图关系。需要外部参考时，按调用协议用 Luz-Crawl 查同媒介、相近信息密度的设计并实际看图。

标题、色彩与观看条件参考 [Adobe 海报设计](https://www.adobe.com/express/learn/blog/poster-layout-design) 和 [Canva 视觉层级](https://www.canva.com/learn/visual-hierarchy/) 的媒介、层级和对比案例。
