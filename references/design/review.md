# 审阅

应用状态按[成品要求](hard-rules.md)核对：全局纯白、界面禁绿与青绿、图形头像、独立业务页面及就近反馈。

用成品检验设计。检查范围与风险相称：改一句文字不用重测全部，新页面要完整任务和代表宽度。记录实际观察，不填没操作过的“通过”；机器检查只能发现一部分，看图与操作必做。

## 先核流程

- 本地调整可从代码、原稿和成品截图核对。有联网研究的设计先完成当前阶段的来源检查，布局、密度、图表或交互的采用理由可定位到实际页面。
- 组件有当前固定版本、真实源码、许可与使用位置；组件默认的弹层、文案、图标不合规时，用公开配置或插槽适配。
- 用户当前明确的条件优先于样板和历史偏好。按[前端背景、头像与图标](hard-rules.md#前端背景头像与图标)核对成品。

## 看图

逐页对照 System 的模块清单。先认出本页对象与关键决定，再自上而下读完各组。核对宽屏并排与窄屏堆叠都保留语义顺序，每个展示项、输入项和动作都落在所属组。用键盘走相同任务，再用长标题、无图或错误状态复核焦点和阅读次序。

先看完整截图：第一眼能否找到主内容与动作；有没有同等强调、平均切卡、大片空白、重复信息。先修构图与任务，再修细节；每轮记录问题、修改、新截图。逐项给出当前成品里的位置，不写统一的“已检查”：

| 项 | 看什么 |
|---|---|
| 构图 | 主内容与当前动作清楚；顶部围绕有用内容收紧，图案不撑成空横幅 |
| 卡片与切换栏 | 同排上下齐边，同一列左右齐边。Web 纵向同组卡片贴合，App 独立卡片留半个正文字号。嵌套圆角与内距协调，切换项有可辨识的选中态与焦点 |
| App 字体与设置入口 | 量相邻行框和卡片边缘。标题、正文、说明用 1.5 倍行高，文字块之间取较小字号。用窄屏和长字验证设置行上下内距、换行以及实际触控范围 |
| 带文字的按钮 | 单行按钮的可见高度约为字号两倍，文字上下留白均衡，同组齐高。放大字号后检查内容与触控边缘 |
| 列表 | 名称、数值、状态、动作稳定对齐，长短行都紧凑，字号与点击面积没被压缩 |
| 表格、表单与数据 | 用长短值和不同位数检查共同边线。短字段居中时，同字段的表头与各行起点相同。金额按位对齐。表单限宽居中时标签、输入和错误提示仍可顺畅逐项阅读 |
| 数据范围切换 | 从上到下检查切换控件先于所有受控信息，切换前后分别确认同一范围只有一组数据。查验窄屏、加载、空态与错误时仍沿用该数据区 |
| 数据与入口 | 对照页头、图表、数据面板与明细，同一口径、同类指标和同一目的地各有一个呈现位置。图型匹配关系，真实值与单位保留，缺失不造零，触屏与键盘取得同样数据 |
| 标识 | 同一对象跨页、刷新、改名后图标稳定，不同对象不重复；素材池不足有真实处理路径 |
| 交互 | 阅读态无保存取消，单字段原位改且按钮相邻，完整表单进独立页面；错误保留输入 |
| 控件状态与移动输入 | 点按文本框与卡片时观察前景、字重或短标记的反馈。悬浮提示、点按与选中均无描边和阴影，键盘焦点有短标记。测试输入换行、长文滚动、清空缩回、文件与图片选择、移除、发送，以及软键盘和安全区下的可用空间 |
| Three.js 动效 | 播放一次后回到静态，离屏时停止。模拟 WebGL 不可用及减少动态效果，确认静态图形与业务内容可用 |

参考页与成品都可以用 `py -X utf8 scripts/teardown.py <网址或文件> --width 390 --lint --md <报告.md> --shots <目录>` 量一遍：字阶与字重、颜色聚类与对比度、圆角、阴影层级、间距基数、留白与触控目标。数值只给线索，偏离了去看图找原因，不靠它判定好看。

分开检查页首和业务区。从截图与真实页面量安全区后的顶部留白、标题容器宽度、工具到首行结果和字段间距。确认页首与概览在白底上清晰可读。选最长标题、字段错误和有效内容实测。无文字图标核对可访问名称、辨识和点击区域。

## 行为

用相同角色、数据和起点走到业务结果。按 [System 任务路径](../../../Luz-System/references/ui-standards.html#short-task-paths)记录实际操作及必要的业务确认。无结果、长中文、错误、返回、撤销与恢复按范围覆盖。键盘焦点、页内返回、触控无悬停路径；禁止表单弹窗与滑动面板，通知与警告的限定例外按硬规则检查。完成与恢复不自动切标签，内容区不重复其它标签入口。动效实际观察，并在系统“减少动态效果”下再看一遍。

## 主要核验项目

- 文案与标题清楚，专名与业务条件完整。窄屏查看标题和字号缩放，检查是否裁切。
- 标题前和左栏图标可按计算字号约 `1em` 同排。底栏和「我的」快捷入口优先上图下字。检查普通功能图标外框与点击范围；已有金刚标逐项对照原素材、尺寸与样式。
- 在默认、悬停、选中、聚焦、禁用和错误状态下检查计算样式和截图。页面与全局导航呈现纯白。图标、按钮和卡片按项目配色检查组件边界，以及文字和图形在实际纯色或渐变上的对比度。
- 核对账户、列表、会话及缺省头像。模拟头像资源加载失败，确认仍显示图形。查看图标的实际字形和资源，逐一排除姓名首字、字符、Emoji、字体图标和图片内的文字。按钮标签与可访问名称要能说明动作。
- 在宽屏和换列后的窄屏分别核对卡片边线。普通显示和折叠后的上下卡片都应接缝为 0，内边距和点击区域按内容独立检查。
- 筛选作用于预期范围，指标名称和单位的关联明确。新建动作归属清楚，纯图标动作有可访问名称及焦点提示。
- 完整填表是独立页面，阅读态没有文本框与保存取消；返回恢复筛选、对象、滚动与焦点。
- 手机浏览器按 [App 规则](app.md#手机浏览器中的稳定界面)检查装载的默认尺度与页面横向边界。滚动、横竖屏、键盘开合、底栏、放大文字和末项均在适用目标端核对。记录实际浏览器与输入方式，分别说明模拟视口与真机的覆盖范围。
- 通知与警告可用成熟弹层，弹层里没有业务输入；单字段纠错原位完成。
- 详情与展开在首项、中间项、末项和长列表都紧邻对象；数值字段原位纵向选择可手输。
- 周范围含真实起止日期且最多到当前周期；图表完整刷新所选周；非维护角色没有计划编辑模块。
- 状态有非颜色线索。实际使用的图片已加载，生成素材的回执及透明边缘已核。

## 三轴分别验证

| 轴 | 在设计中落实 | 交付证据 |
|---|---|---|
| UX 用户体验 | 分组与主次清楚，目标入口最少且完整，输入与反馈就近，图表可读可点，窄屏保留任务 | 真实主任务、取消、失败、恢复，目标尺寸截图与结果 |
| AX 智能体体验 | 控件有中文名称与正确角色，重复动作可在对象区域内唯一定位，动态列表有稳定 ID，结果可从页面与数据观察 | 基于角色、名称、对象范围的真实操作记录；不靠坐标或 nth 猜对象，也不靠截图宣称成功 |
| DX 开发体验 | 沿用框架与成熟组件，共享令牌与业务状态，来源与许可清楚，模块不互相写死，运行与维护可复现 | 真实启动与构建、必要测试、组件使用位置、数据边界与限制 |

AX 是 Agent Experience，不等于无障碍；对比度、焦点、触控、重排另按无障碍规则检查。每轴记录实际收益、中性或退步，不打总分掩盖缺陷；没有基线不声称量化提升。具体指标只从中央 `quality_rules.py` 读取（`list`、`plan`、`check`），前端审阅的 `experience_axes` 分别提供三轴的观察、限制与证据，任一轴缺失或未验证都不能用另外两轴代替。

## 交付

对新建或既有工程运行 `scripts/audit_rendered.py <页面> --frontend-visuals`，核对页面白底、局部色底与渐变、图形头像和字符图标。用 `--walk` 覆盖选中、悬停、错误和头像回退。两个起步模板和整页样板的通用审计也执行这些检查。图片内容、渐变上文字的实际对比度与铺色边界还须看成品。

独立交付的浏览器报告用 `journeys` 声明实际走查。每条记录包含包内入口 `entry`、视口像素宽度 `width` 和有序的 `steps`。每个动作通过 `role` 与精确的 `name` 或 `label` 定位；支持 `click`、`fill`、`select`、`press`、`hover` 和 `focus`。输入、选择与按键的内容写在 `value`。每个入口都要覆盖；有业务填写、校验或返回的路径应进入相应状态。起步模板自带新建与取消路径，修改业务后以实际报告的路径走查。审阅工具在初始渲染和每一步后执行同一浏览器检查，回执绑定成品、规则脚本和各条路径。

对接项目、组件与自动化走查时，等页面、字体及图像就绪，把 `scripts/application_state_rules.js` 的 UTF-8 内容直接传给 Playwright 的 `page.evaluate(source)`。返回数组中的每条记录给出 `rule`、`element`、`detail`。如需完整交互、内容与排版报告，把数组传给 `page.locator("html").evaluate(ui_rules_source, findings)`。图片原色、图形可辨识度、截图细节及未走到的状态仍按实际产物核验。

交付页面或构建、源码、运行方式、组件版本与许可、验证记录和已知边界。审阅绑定当前 `hard-rules.md` 的哈希，`loaded_assets` 列出浏览器实际加载的生成图片。保留主要状态和导航操作的浏览器证据，设计建议可记入审阅的实际观察。审阅字段与封存流程见 [组件复用](../component-reuse.md)。
