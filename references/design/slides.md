# 演示文稿

先定观众、场合、品牌和放映尺寸。画幅、母版、构图及成品校样表见 [PPT 演示设计规范 PDF](handbooks/PPT演示设计规范.pdf)。

## 标题与内容

- **每页一个可见的单行标题。** 封面以文件名为题，例如「库存管理系统说明书」。内页以主题或结论为题，例如「入库作业」「拣货时长缩短 18%」。封面、章节、内页、附录和结束都用标题占位符，让大纲与辅助技术可读取。详见 [Microsoft 幻灯片标题](https://support.microsoft.com/en-gb/powerpoint/title-a-slide)。
- 主标题放在页首，短到能够按放映字号整行读出。长对象名、日期范围、单位、数据口径和需要保留的来源放在对应内容旁。

## 配色与节奏

- 白色 `#FFFFFF` 贯穿封面、内页与结束页。照片、数据标注与重点色块收在局部，章节通过留白、内容和构图转换节奏。
- 可用墨蓝 `#162640` 担任标题和主数据，石板蓝 `#52657C` 用于说明，淡蓝灰 `#EAEFF5` 用于轻分组。浅铜金 `#D2C0A4` 用于小面积点缀。实际放映时核对文字与背景，图表系列结合线型、标记和名称。详见 [Microsoft 演示配色](https://support.microsoft.com/en-us/powerpoint/accessibility/video-use-more-accessible-colors-and-styles-in-slides)。
- 用统一栅格排图文、数据、对比与流程。优先采用真实产品截图、实拍或有授权的插图。图标承担对象、状态或动作的含义，同组保持视觉尺寸、线宽与风格一致。图注靠近图片并保留来源。

## 选模板与核验

按页面任务查阅 [PPT 页面布局图谱](../../templates/documents/slides/PPT页面布局图谱.pdf)。为企业介绍、项目说明和产品发布选参考时，从真实发布稿中优先找同时有主题标题、解释文字、实物或场景图、可核对数据的完整页。拆解原稿中的标题位置、图文边线、数据口径和阅读顺序，保留原稿链接及页码。封面可在白色标题区下放背景照片，也可用图文分栏或插图。目录可用有顺序的议程或可独立进入的主题索引。关系图沿用内容本身的并列、圈层或依赖，图标指向实际功能和术语。

1. 用户要找现成模板时，从发布方取已有的 `.pptx` 或 `.potx`。商务场景优先看中文原稿的封面、正文、图表与表格，选择配色统一、对齐清楚、适合正式场合的完整一套。用户指定 GitHub 时，以仓库内实存文件和涵盖该文件的许可为依据。
2. [文件模板库的 PPT 分类](../../templates/documents/documents.html#ppt)展示商务原件、内页预览、发布方和许可。用户要求先挑选再合并时，将候选原件集中到待筛选目录。用户确认筛选完成后，按目录中留下的原件合并。需要从描述文件制作时，用 [生成样例](../../templates/documents/slides/README.md)。
3. 从母版继承标题和正文的占位符。保留可编辑文字与图表数据，替换样例文案、日期和数值，并按来源要求保留署名。外部模板原件与项目成稿分别保存。
4. 放映逐页检查可见主标题的实际行数、白底、长中文、字体回退、图表单位、投影对比、图文裁切与署名。`scripts/check_document.py <演示.pptx>` 辅助检查比例、字号、边距和标题结构。缺省画幅为 16:9。导出 PDF 后逐页检查最终版本。
