# 演示文稿

先定观众、场合、品牌和放映尺寸，再选一套能承载真实内容的版式。下列是建议。

## 标题与内容

- **每页一个视觉主标题。** 标题说出当页要讲的主题或结论。封面用一个演示名称。主题、结论、口号或英文译名会争抢同一层级时，选择最有用的一条作为主标题。
- 主标题优先简短，长业务名称需要时换行。讲者、图表名、单位、图例、日期、来源、署名和提示按需要用较弱的字号、字重和位置区分。
- 标题放进 PowerPoint 的标题占位符，便于大纲和辅助技术导航。有意使用纯视觉过渡时，可给该页设置隐藏标题。双栏适合对比，图文适合例证，趋势或比较用贴合数据关系的图表。详见 [Microsoft 幻灯片标题](https://support.microsoft.com/en-gb/powerpoint/title-a-slide)。

## 配色与节奏

- 用品牌主色串起全稿。再选择与它协调的辅色、强调色和中性色，在章节、图表和插图中分角色使用。可从两种辅色起步，按品牌和数据扩展。
- 封面、重点数字或章节页可以用饱满的色块、渐变或深背景。长正文与密集数据放在更安静的底上。不同章节可以改变色彩重心，标题位置、文字层级和数据编码保持连贯。
- 例子包括深蓝加青绿与石灰绿的商务提案、海军蓝承托珊瑚与翠绿的品牌发布，以及紫蓝配暖橙的科技路演。图表系列除了颜色还可用线型、标记和文字区分。详见 [Microsoft 演示配色](https://support.microsoft.com/en-us/powerpoint/accessibility/video-use-more-accessible-colors-and-styles-in-slides)。

## 选模板与核验

按页面任务查阅 [PPT 页面布局图谱](../../templates/documents/slides/PPT页面布局图谱.pdf)。从真实内页核对顶部标题、正文区、图表与说明、行动和页脚的位置，再按内容取用。并列项可围绕中心等距排成圆，圈层可用同心双环。上下双层可先给总览再放证据，自底向上架构从底座经处理、能力接到应用，并注明箭头含义。

1. 用户要找现成模板时，从发布方取已有的 `.pptx` 或 `.potx`。商务场景优先看中文原稿的封面、正文、图表与表格，选择配色统一、对齐清楚、适合正式场合的完整一套。用户指定 GitHub 时，以仓库内实存文件和涵盖该文件的许可为依据。
2. [文件模板库的 PPT 分类](../../templates/documents/documents.html#ppt)展示商务原件、内页预览、发布方和许可。用户要求先挑选再合并时，将候选原件集中到待筛选目录。用户确认筛选完成后，按目录中留下的原件合并。需要从描述文件制作时，用 [生成样例](../../templates/documents/slides/README.md)。
3. 从母版继承标题和正文的占位符。保留可编辑文字与图表数据，替换样例文案、日期和数值，并按来源要求保留署名。外部模板原件与项目成稿分别保存。
4. 放映逐页检查主标题、长中文、行尾、字体回退、图表单位、投影对比、图文裁切与署名。`scripts/check_document.py <演示.pptx>` 可辅助发现比例、字号、边距和标题结构问题。画幅和字号按渠道与实测决定。导出 PDF 时同样检查最终文件。
