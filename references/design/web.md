# Web / PC

应用状态按[成品要求](hard-rules.md)核对：全局纯白、界面禁绿与青绿、图形头像、独立业务页面及就近反馈。

桌面浏览器里的操作型产品、展示网站、阅读网站和体验页。按 [成品要求](hard-rules.md) 核对任务和可读性。设计建议与取值见 [视觉基础](foundation.md)，页面结构见 [页面模式](patterns.md)。

## 先定页面目的

同一站点可以有不同目的的页面，导航、语义与品牌保持连贯，结构各自独立。

| 目的 | 内容与构图 | 优先检查 |
|---|---|---|
| 操作 | 导航、工具区、主数据、关联详情；列表、表格、看板、画布按任务选 | 密度、定位、筛选、操作、状态与恢复 |
| 介绍 | 具体价值、真实产品或内容、证据、当前动作；节奏随素材变化 | 主张真实、主焦点、素材质量 |
| 阅读 | 标题、章节、图表与引用；控制行长与层级 | 内容连续、目录、长文与窄屏 |
| 体验 | 作品或交互本身是内容，结构服务展示对象 | 表达、性能、静态替代、可退出 |

不要机械生成“居中大标题、三张卡片、评价、价格”的全套；每一节回答新问题，没有评价和效果数字就不编造。

## 起步

| 起点 | 用在 | 做法 |
|---|---|---|
| HTML 模板 | 定构图、取组件、做原型 | 打开 `templates/web/web.html` 预览（tab：整页模板、组件库），复制 `source/pages/` 的页面和 `kit/`；按编号取组件 |
| 可运行工程 | 要交付运行页面 | `py -X utf8 scripts/frontend.py init web-workspace`（Vue 与 Element Plus）；已有 React、Vue、Svelte 工程沿用其栈 |

Web 模板有五个完整页面：工作台、列表、订单、我的、智能体，另有“组件库”tab：按钮、背景、卡片、布局壳、表格、表单、数据、反馈、智能体、动效十类共二百余个编号组件。组件按编号取用，见 [组件](components.md)。

## 操作型桌面

- **导航与工具分开。** 左侧标签栏图标优先黑色透明底，放在文字左侧，约与标签字号等大；用整项样式提示选中。筛选靠近所控制的内容，详情靠近当前选择。
- **先选范围，再读数据。** 账号、时间和类别切换置于受控区域的开头。账号页按「页面标题 → 账号切换 → 当前账号资料与数据」排列，当前账号名称可以作为选项标签，完整资料集中放在切换项下面。
- **顶部。** 当前页需要对象或任务名称时用简短标题。搜索、筛选和新建靠近所控制的内容。按[视觉基础的间距](foundation.md#间距圆角与层级)组织标题、卡片与输入。手机浏览器按[移动产品页](app.md#手机浏览器中的稳定界面)处理宽度、安全区、键盘和滚动。
- **模块与表格。** 业务卡片按信息关系划分，标题的位置随分组选择。短字段可在列内使用同宽且居中的内容区，表头与各行共用左边线。长文本沿左边线阅读，可比较的值沿右边线读。分页、列宽和表单内容区按数据量与操作密度设置。见 [表格、表单与数据对齐](foundation.md#表格表单与数据对齐)。
- **数据看板。** 同一指标与同一入口各有一个位置。主趋势用折线，累计构成用环形，独立总数用文字。主图卡较宽，构成和辅助模块随视口重排。见[看板配色、布局和取图](patterns.md#数据看板)。
- **独立快捷入口。** 「我的」快捷入口和设置区沿用同套功能图标与透明底。独立入口卡优先上图下字，图形略大于标签，图标外框和图形放在 24 px 以内。设置行和表格内动作可沿用横排。
- **数据。** 趋势、组成、比较、目标用相应图表，保留单位、筛选范围与关键数值；图表点位的明细对键盘与触屏可达。
- **操作。** 详情用常驻分栏或独立详情页，窄屏改为单页；完整填写进独立页面，单字段原位改；允许就近下拉、纯信息提示、通知与居中确认，禁止表单弹窗和边缘滑出面板。

## 智能体工作台

- [助手页模板](../../templates/web/source/pages/agent.html)默认纯白页底，桌面侧栏、手机底栏、对话区和输入区都用白色表面。用中性文字、细分隔线和局部浅灰状态划分层级，主操作用墨黑。状态保留文字与既有语义色。
- 桌面主导航用透明底深色线稿，和标签同行且等大。手机把同一组导航移到底栏，图标在文字上方并略大于文字。会话列表的功能图标共用小尺寸和透明底。
- 宽屏让会话、对话和运行记录的卡片上下齐边。窄屏上下接缝为 0，组外圆角和细分隔线体现层级。输入框和可点击卡片用圆角白底，触点和分段选中用字重或下划线反馈，键盘用高对比短标记。
- 手机用[移动端输入行](app.md#移动端智能体输入栏)，左侧加号添加文件或图片，中间输入框随文字增高，右侧为紧凑的发送按钮。为底栏、键盘和安全区留出空间。

## 展示与阅读网站

按真实材料决定首屏：产品截图、编辑排版、摄影都可以成为主视觉。缺图时先生成适用的图标与图案，不用空占位图假装完成。阅读页控制行长，不在标题周围加导语和阅读建议。

## 交付与验证

简报写明目的、真实页面、主任务与支持宽度。交付实际工程或完整可运行前端，含源码、锁文件或固定本地依赖、许可与运行方式；展示页不虚构后台数据，工作台不能用静态宣传页替代。

从 1440、1200、900、760 等代表视口选取实测范围，检查键盘与焦点、页内返回、缩放、长名称、空数据、排序筛选及恢复。展示页另看滚动节奏与首屏承诺。UX、AX、DX 的证据分别记录，见 [审阅](review.md)。
