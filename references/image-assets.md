# 图像与素材

用本地 Imagegen 制作需要新画的图标与图案，审图后接入成品。已有产品可以沿用成熟组件、授权图像和一致的素材。来源要求见 [成品要求](design/hard-rules.md)，排布与取值见 [视觉基础](design/foundation.md#图标与图像)。

## 资产分两组

| 组 | 用在 | 样式 |
|---|---|---|
| 功能图标 | 底栏、侧栏、工具和「我的」快捷入口 | 复用简明图形。导航优先黑色透明底，「我的」功能图标用统一色 |
| 已有金刚标 | 首页业务宫格 | 保留原素材、尺寸、配色及图文布局 |
| 说明图像 | 商品、品牌、头像，以及需要解释内容的空态和结果页 | 选择有信息的照片、插画或标识，按其内容取图幅 |

HTML 页签图标可以用主色底加白色实心图案。图标通过成熟组件的公开插槽或图片节点使用，控件行为由组件负责。标题与业务文本保持可编辑。人物与品牌素材按实际许可使用。

## 提示词：八个槽位

一个请求一个提示词文件，英文，按槽位写，缺一不可。

| 槽位 | 写什么 | 例 |
|---|---|---|
| 1 用途与位置 | 放在哪、给谁看 | product photograph for a mini-program home banner |
| 2 主体 | 一个主体，写具体属性 | one hand-tied bouquet of dusty-rose roses, kraft paper wrap |
| 3 构图与镜头 | 画幅、占比、边距、机位、景深 | square 1:1, subject fills 65%, 12% margin, eye-level, shallow depth of field |
| 4 光线 | 方向、软硬、阴影 | soft diffused window light from the upper left, one gentle shadow |
| 5 材质 | 表面是什么 | true-to-life petal texture, matte clay |
| 6 色彩 | 主题色 hex 与比例 | dusty rose and sage green are the only saturated colours |
| 7 背景与输出 | 背景色或透明、尺寸、格式 | seamless light-grey backdrop / transparent background |
| 8 负面约束 | 不要什么，写在最后 | no text, letters, logos, watermarks, hands, faces, glitter, neon |

写“是什么”比写“好看”有效：用材质、光线、镜头这类可观察的词，不写“高级、精美”。颜色写 hex 与比例并限定饱和色。同一产品的所有图复用同一段风格描述与主题色，不逐张改写，否则风格会漂。生成图里的文字几乎都不可信，一律不要。只写属性，不写品牌名和在世艺术家名。

## 按角色选配方

| 角色 | 路线 | 画幅与格式 |
|---|---|---|
| 商品图与头图 | 真实感摄影，无缝背景，软光，同组统一光线 | 1:1 或 4:3，不透明 |
| 定制入口图标 | 常用图标不足时可生成同组简单轮廓，按 16–20 像素主体检查 | 1:1，透明 |
| 空态与结果页图像 | 能解释当前对象时选小场景或单物体 | 按内容与容器 |
| 低对比背景 | 柔和纹理、抽象形或材质底，色相与主题一致，文字区留白 | 按顶部或卡片比例 |
| 海报与宣传图 | 文案不交给模型，版面里再加 | 按渠道 |
| 控件图标与整张界面截图 | 不生成：控件来自组件库，界面用真实组件构建 | 无 |

## 流程

1. 写提示词到会话 `raw/02-visual/prompts/NN-名称.txt`。
2. `py -X utf8 scripts/generate_ui_assets.py generate --session <会话> --prompt-file <文件> --id <id> --role background|icon-sheet|illustration --ratio <比例> --resolution 1k|2k|4k --background opaque|transparent`。先 `--dry-run`；一个请求一条记录，全程串行；超时先查回执，不自动重试、不重复计费。
3. 生成器保留原始字节；裁切与压缩另存为派生文件，不把派生尺寸冒称原生返回。
4. 实际看图后 `generate_ui_assets.py review --session <会话> --id <id> --note <复核结论>`，记录内容、边缘、浅深底效果与用途。
5. `ui-assets.json` 记录素材、提示词、回执、派生步骤、哈希与采用位置，切图或降饱和后仍能追到源图。

## 元素拼板

一次请求出 4×4：布局句（严格 4×4，每个居中在自己的格子里，不跨格，同一比例，不画网格线）加风格块、按阅读顺序编号的物体清单、负面约束。物体选名词具体、轮廓简单的，避开带文字或数字的（日历、价签、钟表）。切图用 `py -X utf8 scripts/cut_element_sheet.py <拼板.png> <输出目录> <名称…>`，切完逐个排除邻格碎片。

## 复核

| 检查 | 做法 |
|---|---|
| 内容正确 | 逐个对照物体清单与数量，不对就改物体名重来，别重写风格块 |
| 无文字、标志、人脸、手 | 放大看；不过就加强负面约束或弃用 |
| 风格一致 | 并排看同组图的光线、色温、材质；偏的那张重生成 |
| 透明边缘 | 在浅色与深色底上各合成一遍再判断，毛边与彩色渗边要处理；`scripts/check_icon_image.py` 检查，`soften_icon_image.py` 处理 |
| 色彩 | 落在主题色附近，`scripts/audit_palette.py` 核对 |
| 尺寸 | 记录实际像素；屏幕按显示尺寸的 2 倍，印刷按成品宽度算 300ppi 以上 |
| 实际尺寸识别 | 按显示尺寸看，能立即识别；含义不清的动作改短中文，不靠增加图形细节 |

## 稳定的对象标识

客户、联系人这类需要区分个体的对象，先批量生成同风格素材池，再裁切审图，清单记录风格版本、原图来源、资产 ID、路径、哈希与排除项。

- 首次分配可随机或按对象 ID 取稳定顺序，但必须持久化为“对象 ID → 资产 ID”，存储层保证资产不重复占用；改名、换业务线、排序、重载都不改变。
- 批量素材要检查重复字节和近似轮廓并看联系表；只换色不算不同图标。
- 新增素材沿用同一风格参考，不覆盖已用文件；池耗尽时保留创建业务并暂时省略标识，在交付记录说明缺口，不循环复用、不用文字头像、不临时换风格；后补图只填空位。
- 生成的识别标记不是客户真实品牌标志，不能对外冒称官方商标。

## 常见问题

| 问题 | 对策 |
|---|---|
| 图里有乱码文字 | 负面约束加 text、letters、numbers、labels；物体清单去掉带字的物体 |
| 风格逐张漂移 | 风格块原文复用；一次出拼板；样张通过后再批量 |
| 透明底有彩色渗边 | 浅深两种底上检查；改用纯色背景再抠图 |
| 玻璃像塑料 | 写透明度百分比、边缘高光位置、能透过看到什么 |
| 摄影像 CG | 写镜头感、光线方向与软硬、真实材质纹理 |
| 色彩过饱和 | 写 natural colour，并限定只有哪几种饱和色 |
| 主体太满裁不了 | 写占比与边距：fills 65%, 12% margin |

模板库自带的素材清单在 `kit/assets/manifest.json`，可用于起步和维护。新增客户或业务记录可复用已审素材池。核对实际采用的素材、来源及用途。
