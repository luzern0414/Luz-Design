# 素材生成手册（Imagegen：怎么得到“高级”的图）

规则的底线仍在 `visual-design.html › 图像生成` 与 `SKILL.md › Imagery with the local image service`：实拍优先、没有实拍才生成、一个请求一个提示词文件、先试运行、逐张串行、超时不自动重试、生成后逐张复核。本页补的是“怎么写出好提示词、怎么检查、怎么控制成本”。提示词模板在 `prompt-image.txt`。

## 1 提示词解剖：八个槽位，缺一不可

| 槽位 | 写什么 | 例（花束商品图） |
|---|---|---|
| 1 用途与位置 | 这张图放在哪、给谁看 | Product photograph for a florist mini-program home banner |
| 2 主体 | 一个主体，写具体属性（数量、材质、状态） | one hand-tied bouquet of dusty-rose garden roses (about nine stems) with eucalyptus, kraft paper wrap |
| 3 构图与镜头 | 画幅、主体占比、边距、机位、镜头感、景深 | square 1:1, bouquet fills 65%, 12% margin, eye-level, 85 mm look, shallow depth of field |
| 4 光线 | 方向、软硬、阴影 | soft diffused window light from the upper left, one gentle soft shadow to the lower right |
| 5 材质与质感 | 表面是什么 | true-to-life petal texture, paper fibres; frosted glass 35% translucency; matte clay |
| 6 色彩 | 用主题色 hex 与比例 | dusty rose (#B2465F family) and sage green are the only saturated colours |
| 7 背景与输出 | 背景色或透明、尺寸、格式 | seamless warm light-grey backdrop #EDE7E4 / transparent background |
| 8 负面约束 | 不要什么（写在最后一句） | no text, letters, logos, watermarks, hands, faces, glitter, neon, lens flare |

要点：
- **一个提示词一个主体**。多个物体用元素拼板（见 4）。
- **写“是什么”比写“好看”有效**：用材质、光线、镜头这些可观察的词，不写“高级、精美、梦幻”。
- **颜色写 hex 和比例**，并说“只有这几种饱和色”，否则模型会自己加色。
- **负面约束永远写**，尤其是文字、标志、人脸、手、闪光和霓虹。生成图里的文字几乎都是错的，一律不要。
- **风格块（style block）复用原文**：同一产品的所有生成图，用同一段风格描述、同一组主题色，不逐张改写，否则风格会漂。

## 2 按资产角色选配方

| 角色 | 路线 | 画幅与格式 | 关键词重点 |
|---|---|---|---|
| 商品图 / 头图 | 真实感摄影 | 1:1 或 4:3，不透明，png 或 webp | 无缝背景、软光、浅景深、同组统一光线与背景 |
| 入口图标 | 4×4 元素拼板，一次出 16 个 | 1:1，2k，透明 png，再用 `cut_element_sheet.py` 切图 | 一段风格块 + 16 个物体按阅读顺序列出 + 每个占格子 70% |
| 空状态 / 结果页 | 单物体或小场景插画 | 4:3，透明 | 与入口图标同一风格块 |
| 主视觉装饰（毛玻璃、软陶物体） | 单个物体 | 3:4 或 1:1，透明 | 材质写透明度与边缘高光；不要地面、桌面、背景 |
| 海报 / 宣传图 | 见 poster 卡与 `prompt-image.txt` 的 Poster 模板 | 按渠道 | 文案不交给模型，版面里再加 |
| 控件图标 / 界面截图 / 背景纹理 | **不生成** | — | 控件图标始终是 2px 线性矢量 |

## 3 流程（每次都这样）

1. **前提**：用户已选定风格与作用范围并写进 BRIEF（`style_match.py` 的 approval 为 approved），**或者用户在本次请求里明确要求生成**（这时在 BRIEF 写下用户原话作为依据，生成物只作风格样张，不当正式资产）。没有这两条，不调用 Imagegen。
2. **写提示词文件**：`raw/02-visual/prompts/NN-名称.txt`，每张图一个文件，英文，按八个槽位写。
3. **试运行**：`py -X utf8 D:\Codes\Imagegen\src\imagegen.py --prompt-file <文件> --ratio <> --resolution <> --quality high --format png [--background transparent] --output-dir <raw/02-visual/generated> --dry-run`，核对尺寸、质量、背景参数。
4. **串行生成**：一次一个；超时不重试，先看服务记录有没有结果。
5. **复核**（见 5）；不合格改提示词的某一个槽位重来，不整段重写。
6. **登记**：BRIEF 里记提示词文件、尺寸、格式、复核结论与用途；对外交付的图要有权利说明（生成图，非第三方素材）。

## 4 元素拼板（入口图标一套 16 个）

- 一次请求出 4×4：布局句（严格 4×4、每个居中在自己的格子里、不跨格、同一比例、不画网格线）+ 风格块 + 物体清单（按阅读顺序编号）+ 负面约束。
- 物体选择：名词具体、轮廓简单（花束、绿植盆栽、礼盒、花瓶、喷壶、配送车、优惠券、购物袋、爱心、星、礼品卡、幼苗、定位针、购物车、剪刀）；避开带文字或数字的物体（日历、价签、钟表）。
- 切图：`py -X utf8 scripts/cut_element_sheet.py <拼板.png> <输出目录> <名称1> … <名称16>`，输出每个 240px 的 WebP；切完逐个核对没有邻格碎片。
- 实测（2026-11-04）：2k（2048×2048）的拼板一次得到 16 个形态正确、风格统一的软陶图标；用作 120px 以内的入口图标足够。

## 5 复核清单

| 检查 | 做法 | 不过怎么办 |
|---|---|---|
| 内容正确 | 逐个对照提示词里的物体清单与数量 | 改物体名重来，别重写风格块 |
| 无文字/标志/人脸/手 | 目视放大看 | 加强负面约束，或弃用 |
| 风格一致 | 并排看同组图的光线、色温、材质 | 重新生成偏离的那张，风格块不改 |
| 色彩 | 用 `scripts/audit_palette.py` 或取色看是否落在主题色附近 | 提示词里把 hex 与“只有这几种饱和色”写明 |
| **透明图** | **必须在浅色底和深色底上各合成一遍再判断**（很多看图软件把透明像素按黑色显示，会把隐藏的色块当成“光晕”；真正的问题是边缘毛边与彩色渗边） | 有渗边：改用纯色背景生成再抠图，或在提示词强调 clean edges, no halo |
| 尺寸与分辨率 | 记录实际像素；屏幕用 2 倍显示尺寸；印刷按成品宽度算 ppi（≥300） | 不够就不用或换更高档位 |
| 可裁剪 | 主体周围留约 12% 边距，能裁成目标比例 | 提示词里写边距与取景 |

## 6 成本与节奏

- 每次请求计费：先做一张样张确认方向，再批量；不要为了“多选”并行开多个请求。
- 样张预算：一次风格板试做不超过 3 个请求（商品摄影 1 张 + 主视觉装饰 1 张 + 图标拼板 1 张）；超出先问用户。
- 复用：同一对象在各处用同一张，不同对象不共用；生成的图放进 `raw/02-visual/generated/`，不要重复生成同一个物体。
- 成品：入口图标切图后的 WebP 才进页面；原图留在 `raw/`。

## 7 常见翻车与对策

| 翻车 | 对策 |
|---|---|
| 图里有乱码文字 | 负面约束加 text, letters, numbers, labels；物体清单里去掉带字的物体 |
| 风格逐张漂移 | 风格块原文复用；一次出拼板；样张通过后再批量 |
| 透明底有彩色渗边 | 在浅深两种底上合成检查；改用纯色背景再抠图 |
| 玻璃看起来像塑料 | 写透明度百分比、边缘高光位置、能透过看到什么；不要写 glossy |
| 摄影像 CG | 写镜头感（85 mm）、光线方向与软硬、真实材质纹理，不写 render |
| 色彩过饱和 | 写“natural colour, no retouching glow”，并限定只有哪几种饱和色 |
| 主体太满裁不了 | 写占比与边距：fills 65%, 12% margin |
| 组图比例不一 | 同组统一画幅、占比、机位，生成后统一裁切 |

## 8 从真实参考到提示词

参考研究（`reference-research.md`）量出来的指纹直接进提示词：色板 → 第 6 槽位的 hex；留白比例与主体占比 → 第 3 槽位；光线与背景处理 → 第 4、7 槽位；图片调色 → 风格块。**只写属性，不写品牌名、不写在世艺术家名**。
