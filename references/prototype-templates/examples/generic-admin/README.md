# 通用示例：商品与订单运营后台

这是某个行业（商品与订单运营）的**一种答案**，不是后台的默认值：菜单、工作台、页面组成都不要照搬到别的项目里。它的用处是展示后台模板的机制能做出什么，以及一份完整规格长什么样。另一个行业的答案见 `../service-admin/`（预约与核销，没有商品和订单）。

```text
py -X utf8 scripts/build_prototype.py references/prototype-templates/examples/generic-admin/spec.json --out generic-admin.html
```

- `spec.json`：规格（19 个页面）；`content.js`：内容模块（按固定随机数生成虚构的演示数据，加一个自定义页面“个人中心”）。
- 品牌“星屿运营台”和全部数据是虚构的；图片只用组件库的素材（`assets/products`），头像是默认卡通动物。
- 菜单用分组节点写：“交易”“会员与营销”是分组标题（子项带图标），“财务与权限”是手风琴父项（子项不放图标，宽屏同一时刻只展开一个，图标栏里点开悬浮菜单）。外壳数据写顶层 `shell`；跳转边由 `edges()` 自动报出，页面里没有手写的 `links`；工作台的每个模块和 `blocks` 项都写了 `id`、`name`，场景面板的“模块显示”可以逐个关掉。

## 页面与菜单

| 菜单 | 页面 | 写法 |
|---|---|---|
| 工作台 | `dash` | `dashboard`：5 张指标卡（较上期涨跌）、可关闭的预警、趋势（3 个指标切换）、渠道占比、待办（直达已筛选的列表）、商品排行、最新待发货；时间范围 7 / 14 / 30 天统一控制 |
| 交易 › 订单 | `orders` + `order-detail`（居中面板） | `list`：默认“待发货”（等得最久的在前），状态标签带数量，筛选、更多筛选、批量发货、行内发货、关闭订单（二次确认）、导出预览、分页 |
| 交易 › 商品 | `products` + `product-edit`（二级页，带面包屑）+ `res-saved`（结果页） | `list` + 行内上下架开关（库存为 0 时回滚并写原因）+ 长表单（必填、失焦校验、图片选择、标签、字数） |
| 会员与营销 › 会员 | `members` | `list`：账号启用开关、送积分、注销会员（二次确认） |
| 会员与营销 › 营销活动 | `promo` + `promo-edit`（居中面板表单） | `list` + 表单面板（滑块、日期、点遮罩不关闭、草稿保留） |
| 会员与营销 › 评价 | `reviews` + `review-reply`（居中面板表单） | `list`：默认“待回复”，低分在前；回复必填 |
| 财务与权限 › 财务对账 | `finance` + `res-empty`（空结果页） | `list`：金额右对齐、表尾合计行；只对管理员与运营开放 |
| 财务与权限 › 角色权限 | `roles` | `blocks`：库组件 AD-MGMT-001；只对管理员开放，其他角色看到无权限页 → `res-denied` |
| 财务与权限 › 操作日志 | `audit` | `list`：默认只看警告；经营设置、发货、上下架的修改都会写入这里（闭环） |
| 系统设置 | `settings` | `settings`：经营设置（退款手续费、储值扣减顺序、配送费、退单后的优惠券、自动接单、未支付自动关闭） |
| 顶栏 | `notice`（通知中心）、`profile`（个人中心） | `blocks`：AD-COMM-005；`custom`：库的个人资料组件 + 自己的最近登录卡 |

角色：管理员、运营（看不到角色权限）、只读（除角色权限外所有页面都能看，写操作禁用并说明原因；`roles[].readonly`）。业务场景：行内开关结果、保存与操作结果（成功 / 处理中 / 各种失败原因）。

## 想改成自己的项目时

只保留机制，换掉内容：把 `nav`、`pages`、`data.maps` / `data.options`、内容模块里的数据生成换成项目自己的；每个页面的 `logic` 按项目的功能说明写。机制的用法见 `../../admin/README.md`。
