# Luz Design 会话模板
# 模板只是骨架，不是规范。动手前先运行 py -X utf8 scripts/context.py <任务类型>，读完规则卡（用户偏好、教训、规范原文、工具、检查）再填模板；
# 模板与规则卡冲突时按规则卡改模板内容。new_session.py 会把规则卡存进 raw/00-rules/，发布前 BRIEF 必须填写“采用的规则”。
# 每个模板以 “=== template: 名称 ===” 开始、以 “=== end ===” 结束；scripts/new_session.py 的 read_template(名称) 按名称读取。
# 修改模板时只改块内内容，不改标记行。
# 网页模板的 {{TAB_ICON}}（标签页图标 <link rel="icon"> 的地址）由 new_session.py 的 fill_icon_slots 按会话标题选图案与主题主色填入；
# 其他生成网页用 py -X utf8 scripts/new_session.py icon 页面或系统名 取得。图案与绘制规范见 visual-design.html“网页图标与品牌标识”。
# 网页模板 :root 里的颜色、页面底色与层级令牌只是占位，按本次主题从 references/themes.json 取值重写；页面保留模板默认样式时 check_document.py 给出警告。
