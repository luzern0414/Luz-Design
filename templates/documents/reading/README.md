# 阅读网页模板

六个阅读页版式模板和十六个可复用块。每个模板有一份描述文件（`specs/`）和一份样例 HTML（`samples/`）。样例用虚构门店“花间集”的内容，只有版式参考价值，不是客户成品。

版式取 `references/md-type.css` 的母本字阶（桌面正文 18、手机 16，表格 16 与 14，最小 14），单栏、版心 880 像素、正文行宽不超过 42 字；浅色底，内容直接放在底色上，不给每节套卡片，不用阴影；一页一个主色，按行业主题取色；字体只有一条系统无衬线字体栈。全部规则见 `context.py reading-html` 规则卡。

## 命名

`DC-RD-三位序号-中文名.html`，描述文件同名 `.json`。可复用块编号 `DC-RD-P01` 起，文件在 `specs/parts/`。清单与块的登记见 `manifest.json`。

## 描述文件格式

阶段汇总页（`"renderer": "make_summary"`）的 spec 同时是 `make_summary.py` 的合法输入，格式写在该脚本开头。其余页面：

```
{"id": "DC-RD-001", "title": "主标题", "theme": "salon", "icon": "ledger",
 "sections": [{"title": "节名", "blocks": [块…]}],
 "sources": [{"publisher": "", "title": "", "url": "", "locator": "", "checked": "2026-11-09"}]}
```

- `theme` 取 `references/themes.json` 的行业主题键，`icon` 取 `new_session.py` 的标签页图案名（book bowl chip document dumbbell grid ledger magnifier megaphone palette plane radar store）。
- 块类型：`paragraph` `list` `h3` `table` `conclusion` `quote` `chart`（`bar` `donut` `stack`）`flow` `layers` `code` `figures`，字段见各块片段。
- 行内写法：`**粗体**`、`` `代码` ``、`[^n]`（就近指向 `sources` 第 n 条）。
- 超过 8 节（含参考来源）自动在首节后生成章节链接；有 `sources` 时文末自动生成“参考来源”一节。

## 怎么换内容

1. 复制对应的描述文件，改标题、节与块；`manifest.json` 里每个模板的 `fields` 列出要改的字段。
2. 标题写短，单行，不加标点；第一行是主标题，主标题与第一节之间、每个标题与它的第一项内容之间不放导语、摘要和介绍。
3. 不写建议、推荐行动、下一步和阅读指引；关键主张就近用 `[^n]` 指向来源，文末列发布方、真实标题与链接、定位和核对日期。
4. 图表的数字必须来自真实数据：环形图只放同单位、非负、互斥且合成完整总体的项目，条形图写明单位，不用颜色单独承载含义。
5. 样例里的数字都是虚构的版式演示值，换成真实数据前不得对外使用。

## 怎么生成

正式交付：用 `new_session.py --modes document` 建会话，页面写完用 `publish.py` 发布；汇总页用 `make_summary.py <spec.json> <会话目录> --check`。这些命令需要会话与前置检索门禁，写完登记哈希。**正式交付必须走正式命令与门禁。**

本库的样例不走门禁：`tools/build_reading_samples.py` 直接调用 `make_summary.render`（汇总页）和脚本里的 `render_page`（其余页面），再跑 `check_document.py`。

```
py -X utf8 templates/documents/reading/tools/build_reading_samples.py [--only DC-RD-001]
```

## 怎么检查

- `py -X utf8 scripts/check_document.py <样例.html>`：零 ERROR。
- 浏览器 1440 与 390 宽各看一遍：第一行是主标题，正文 18 与 16 像素，最小文字 14 像素，没有横向页面滚动，表格、图表、流程与分层图在窄屏改为竖排或在容器内换行。
- 行高 1.5 倍、段间距 2 倍、字间距 0.12 倍后，样例没有裁切文字。
- 页面里 `luz-md-type` 标记之间的字阶与 `references/md-type.css` 母本逐字相同。

## 已知限制

- `render_page` 是本库的样例渲染脚本，没有接入会话与门禁，也不登记哈希；要作为正式生成器，需要接入 `design_output_gate.py` 与模板选择记录。
- 样例中的数字与内容都是虚构的。阅读报告的 15 单订单取自表格模板 DC-XL-008 的同一批虚构订单。
- 引用块里的英文是逐字照录的第三方原文，页面其余可见文字全中文；来源标题保留原文标题。三条引用已与原页面正文逐字比对，但只读了页首定义句，没有走 Crawl 前置检索与正文阅读门禁，不能直接当作正式文档的依据。核对日期为 2026-11-09。
- 环形图用画布和少量脚本绘制，右侧列表是同一组数据的文字版；条形图、堆叠条形图、流程与分层图全部是 DOM。阅读页的深色填充只出现在 20 像素高的条与色块上，因为检查器按“小于一行文字的元素”放行。
- 汇总页用 `make_summary.py` 自带的版式（白色纸面和默认链接色），与其余阅读页的版式不同。
- 在 Edge 的 1440 与 390 宽下查看过，没有用辅助技术实测，没有做完整的键盘焦点顺序测试，没有看打印预览。
