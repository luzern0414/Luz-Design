# 海报模板库

十二个海报基础模板（示例内容是花店“花间集”，颜色、图标形态、背景都可换）。入口是同一文件夹里的 `poster.html`（tab：海报模板、提示词库），源文件在 `source/`：`source/templates/` 是十二个海报，`source/prompts/` 是提示词库。每个模板是一份独立的 HTML，双击即可预览，文字全部是可编辑文本，主题色与素材来自 `kit/`。目录页 `index.html` 缩放实时预览全部海报，可按用途筛选、搜索、换主题色、复制编号。

## 目录

```
templates/poster/
  index.html            目录页
  templates/            PS-NNN-名称.html，十二个海报
  prompts/              提示词库，生成背景与主视觉
  README.md
scripts/export_poster.py  导出 PNG 与 PDF
```

## 命名

`PS-NNN-名称.html`。`PS` 表示海报，`NNN` 三位序号从 001 起连续不重号，名称是 4 到 8 个汉字。编号写在画布根元素的 `data-cid`，同时带 `data-name`、`data-size`、`data-use`，导出脚本与目录页都读这几个属性。新增海报接着往后编号，不复用旧号。

## 换文案

文字在 `<main class="poster">` 里。替换完内容后按 [海报设计](../../references/design/poster.md) 复核构图，必要时随内容调整字号、断行和布局。

- 优先保留一个主标题。文字较长时可去掉模板的 `x-nw` 或相应 `white-space: nowrap`，检查行尾、字阶和与主视觉的空间。
- 辅助文案、标签、价格和正文按信息价值定字阶。时间、地点及活动条件采用实际资料。
- 二维码处只是占位框，写着“扫码”。换成真实二维码图片并确认可扫，印刷时留足静区。
- 图标与花卉图片放在 `kit/assets/`，路径写 `../../../kit/assets/...`，不要把文字烤进图里。

## 换主题

可用 `PS-001-活动竖版.html?theme=navy` 切换预设，完整列表见 `kit/tokens.css`。用 `?color=%23385fa8` 设置自定义主色，`?bg=dots` 切换背景效果，`?icons=3d` 切换图标形态。模板从共享令牌读取色值。

目录页的主题色按钮通过 `postMessage({ lz: 'skin', theme })` 让预览里的海报同步换色，页面自己也支持这条消息。

## 预览与导出模式

- 直接打开：画布按窗口大小等比缩放并居中，带浅色外框。
- 加 `?export=1`：去掉缩放与外框，画布左上角对齐，用于截图、导出与目录页的缩略预览。
- 加 `?bleed=1`：只对 PS-007、PS-008 有效，画布四周外扩 3 毫米出血，背景与图片铺满出血，文字仍在裁切线内。预览时画布外四角会显示裁切线，导出时不带。

## 导出

先安装 python 的 playwright，本机已装 Edge。

```
py -X utf8 scripts/export_poster.py templates/poster/source/templates/PS-001-活动竖版.html out.png --scale 2 --theme rose
py -X utf8 scripts/export_poster.py templates/poster/source/templates/PS-007-课程招生A4.html out.pdf
py -X utf8 scripts/export_poster.py templates/poster/source/templates/PS-007-课程招生A4.html out-bleed.pdf --bleed
```

- 画布大小取自 `data-size`；`--bleed` 时以实际外扩后的画布为准。
- PNG 按 `--scale` 放大，默认 2，即 1080 宽导出 2160 宽。
- PDF 只出一页，页面尺寸等于画布尺寸；A4 版得到 210×297 毫米，出血版得到 216×303 毫米。
- 色彩模式、字体嵌入与分辨率按印厂要求另行确认；PDF 为屏幕色彩空间，送印前由印厂或排版软件转换。

## 与提示词库配合

1. 在 `prompts/` 提示词库里选对应提示词，生成背景、主视觉或花卉图，保留提示词、原始返回与用途。
2. 生成图放进自己的素材目录，不覆盖 `kit/assets/` 里的起步素材；在模板里把 `<img src>` 或背景换成新图。
3. 重新用 `?export=1` 看全幅，再看实际观看尺寸，检查标题、焦点、关键事实、文字与底的对比不低于 4.5:1。
4. 图片里的文字不承担事实，标题、价格、时间、地点始终是模板里的可编辑文本。

## 新增一个海报

1. 复制最接近的模板，改文件名与 `data-cid`、`data-name`、`data-size`、`data-use`，并改 `:root` 里的 `--pw`、`--ph`。
2. 在 `index.html` 复制一张 `<article class="item">` 卡片，改编号、名称、尺寸、用途与 `iframe` 的 `src`、`width`、`height`、`data-w`、`aspect-ratio`。用途是新的就补一个筛选标签。
3. 在三种主题下各看一次，确认控制台没有错误。

## 版式约定

- 优先建立一个焦点。主视觉、标题和必要信息按受众的阅读顺序组织。
- 1080 像素宽以上的样板中，标题常在 92 至 156 像素，正文约 28 至 34。印刷、手机平台和其它比例按实际观看大小重新调节字级。
- 不出现界面按钮、卡片外壳、导航与悬浮层；二维码占位、价格章、边框线都是版面元素。
- 纹理低对比，铺在主内容之外；有图的文字区先做遮罩或留白。
- 全部可见文字为中文，品牌名与门店名按业务内容保留。
